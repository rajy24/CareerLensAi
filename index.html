About CareerLens & Methodology

Product architecture, matching mechanics, data privacy standards, and system design specifications.

Product Overview

Purpose and design objectives

CareerLens is a focused career planning and job-readiness workspace. It helps students and early-career job seekers navigate the transition from learning to employment with clarity and structure.

Rather than relying on opaque black-box scoring systems, CareerLens gives users full visibility into how their skills compare with industry postings, what specific competencies are missing, and what concrete steps will bridge those gaps.

  • Deterministic & Explainable: Match percentages are computed through clear set-intersection arithmetic.
  • Private by Design: Your profile data and job search notes stay in your browser via localStorage.
  • Zero External Dependencies: Fully functional offline without requiring third-party subscriptions or API keys.

How Skill Matching Works

Deterministic keyword extraction and comparison algorithm

  1. Text Normalization: The job description text is cleaned and standardized to lowercase, preserving technology identifiers like c++, c#, .net, and node.js.
  2. Token-Boundary Matching: Keywords are extracted using strict boundary patterns so substring collisions do not occur (e.g. java does not trigger javascript, and c does not match css).
  3. Synonym & Alias Resolution: Common abbreviations and naming variations are mapped to canonical keys (e.g. react.js → react, postgres → postgresql, ts → typescript).
  4. Set Intersection Calculation: The system identifies matched skills ($S_{\text{Matched}} = S_{\text{Profile}} \cap S_{\text{Job}}$) and missing skills ($S_{\text{Missing}} = S_{\text{Job}} \setminus S_{\text{Profile}}$).
    \(\text{Match Percentage} = \left(\frac{|S_{\text{Matched}}|}{|S_{\text{Job Detected}}|}\right) \times 100\%\)
  5. Zero-Denominator Guard: If no valid technical competencies are detected in the job description, the application clearly requests a more detailed requirements section rather than producing an arbitrary 0% score.
